# Requisitos do UrnaLab

## Tipo de sistema

O UrnaLab será um sistema desktop de votação escolar nominal, executado offline em um computador Windows.

## Usuários

- Administrador
- Mesário
- Aluno

## Regra principal

O mesário buscará o aluno pelo RA/matrícula no banco de dados. Se o aluno estiver ativo e ainda não tiver votado, o mesário poderá liberar uma votação.
